# 🌿 معزّز صور الطبيعة

موقع بسيط لتحسين صور الطبيعة باستخدام الذكاء الاصطناعي.

## ✨ المميزات
- رفع الصور بالسحب أو الضغط
- تحسين تلقائي للصور
- خصوصية تامة (كل شيء في المتصفح)
- تحميل الصورة المحسّنة

## 🚀 كيفية الاستخدام
1. ارفع صورتك
2. اختر قوة التحسين
3. اضغط "حسّن الصورة"
4. حمّل النتيجة
